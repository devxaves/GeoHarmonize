System Architecture & Problem Statement

AI-Assisted Multi-Source Geospatial Land Record Integration (SIH PS 26013)

GeoHarmonize ingests multi-source, multi-format geospatial land data (drone ORI imagery, legacy cadastral maps, revenue records, municipal GIS layers, GNSS survey points) and harmonizes them into a single, confidence-scored parcel database. Every decision is explainable, reversible, and backed by an append-only PostGIS audit log.

Spatial Pipeline

PostGIS + Shapely + GeoPandas

IoU, Hausdorff distance, CRS transformations, topology repair.

Confidence Formula

5-Factor Weighted Scoring

35% Geometry, 20% RapidFuzz Name, 15% ID, 15% Reliability, 15% Recency.

Auditability

Append-Only Versioning

Super-seded pointers, full state JSON logs, no hard deletes.

REST API Specification

POST /api/geo/datasets/upload — Vector/raster upload, CRS detection

POST /api/geo/datasets/{id}/harmonize — Spatial matching & conflict scoring

GET /api/geo/parcels — List harmonized parcels with version history

GET /api/geo/conflicts — Spatial conflict queue with score_reasons

POST /api/geo/conflicts/{id}/decision — Record human approval/rejection

GET /api/geo/export/geojson — Export GeoJSON FeatureCollection

GET /api/geo/export/geopackage — Export QGIS-ready GeoPackage (.gpkg)
